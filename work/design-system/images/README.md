# Images for Design system

Drop this project's images here (PNG, JPG or WebP, ideally under 500 KB each).
Then in ../index.html, find a `<div class="frame" ...>` and put an `<img>` inside it:

```html
<div class="frame" data-label="..."><img src="images/my-screen.png" alt="What the image shows" loading="lazy"></div>
```
