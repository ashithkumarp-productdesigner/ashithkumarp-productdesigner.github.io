How I work

From ambiguity to a number that moved.

The same loop runs through every project, whether it is an AI workflow for consultants or a check-in flow for millions of travellers.

  1. 01 / Frame

    Name the real problem

    Turn an open-ended brief into a clear question and the business KPI it should move.

  2. 02 / Listen

    Talk to users myself

    Interviews, analytics and usability tests, so assumptions are checked before they become decisions.

  3. 03 / Systemise

    Fix the logic first

    Map the workflow as a system, remove redundant steps, and set the rules the interface will follow.

  4. 04 / Prototype

    Design with the team

    High-fidelity Figma prototypes built with product and engineering, ready to ship without rework.

  5. 05 / Measure

    Prove it shipped well

    Stay through launch, measure time on task, error and adoption, and feed it back into the next cycle.
